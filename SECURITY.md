# Security Policy

Language: English | [简体中文](SECURITY.zh-CN.md)

## Supported versions

Security updates are handled for the latest public source revision only.

## Reporting a vulnerability

Please report vulnerabilities through GitHub Security Advisories when the repository is published. If advisories are not available, contact the maintainer privately before disclosing details publicly.

Do not open public issues that contain exploit steps, private environment details, tokens, or personal data.

## Abuse and misuse

This project is intended for authorized testing and local research. Requests for unauthorized deployment, evasion, or misuse are out of scope and will not be supported.
